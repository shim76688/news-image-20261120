An entry for the make.fun [news-image-20261120](https://make.fun/competitions/news-image-20261120) competition: a program that draws one image summing up the world's news of Friday 20 November 2026 — Cyclone Akvan's landfall in India, Europe's readiness for talks with Russia on Ukraine, mystery drones shutting Genoa airport, the posthumous pardon of baseball legend Pete Rose, and the Kakao founder's acquittal on appeal.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`. Node 22, standard library only; the program draws every pixel itself and writes `/output/entry.png` deterministically.
